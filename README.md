## install

### vencord/betterdiscord (or any client that supports theme files)

1. download the theme file, [`system24.theme.css`](https://github.com/aShroomie/system24-ember/blob/main/theme/system24.theme.css). (there should be a download button at the top right of the page)
2. drag the file into your theme folder. (there should be a button to open the theme folder in theme settings)
3. (optional) customize the theme by editing the options in `system24.theme.css`.
